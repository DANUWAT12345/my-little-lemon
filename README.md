# Little Lemon Restaurant - Portfolio Web Application

This is a portfolio demonstration project showcasing a modern, responsive web application for Little Lemon, a fictional Mediterranean restaurant. Built with **React.js**, **React Bootstrap**, and modern web development best practices, this project demonstrates comprehensive frontend development skills.

---

## Project Overview

Little Lemon is a portfolio website created to showcase web development capabilities through a complete restaurant web application. The project features online ordering, table reservations, menu browsing, and interactive elements, all built with modern frontend technologies.

**Note:** Little Lemon is a fictional Mediterranean restaurant. All content, locations, and services are simulated for educational and demonstration purposes only.

---

## Features

- **Responsive Design** — Fully responsive across all devices (mobile, tablet, desktop)
- **Modern React Architecture** — Built with reusable and modular React components
- **React Router Navigation** — Seamless client-side routing for smooth page transitions
- **Bootstrap Components** — Professional UI components and consistent styling
- **Form Validation** — Robust form handling with Formik & Yup validation
- **Interactive Maps** — Integrated location maps for enhanced user experience
- **Clean & Maintainable Code** — Following React best practices and coding standards
- **SEO-Friendly Structure** — Optimized for search engine visibility
- **Online Ordering System** — Browse menu and place orders
- **Table Reservation** — Book tables with date and time selection
- **Contact Information** — Easy access to restaurant details and contact methods

---

## Technologies Used

- **React** — Frontend JavaScript library for building user interfaces
- **React Bootstrap** — UI framework for responsive design and components
- **React Router** — Client-side routing and navigation
- **JavaScript (ES6+)** — Modern JavaScript for application logic
- **HTML5 & CSS3** — Markup and styling
- **Node.js** — Runtime environment for development
- **NPM** — Package manager for dependencies
- **Formik & Yup** — Form validation and management
- **SCSS** — CSS preprocessor for enhanced styling capabilities

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd my-little-lemon
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
